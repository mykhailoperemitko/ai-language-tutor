# AI Language Tutor Funnel

This funnel is here to do one job: get someone interested enough in the English product that they leave their email for a personalized plan.

The order matters. We start with easy stuff, make the product feel real, get the user to describe their problem, then ask for the email only after the whole thing feels personal.

## How The Funnel Works

### 1. Age
This is just an easy opener. Low effort, no pressure, gets the person moving.

Why it exists: frictionless first click.

### 2. Native Language
Same job here. Still easy, still fast, still not asking the user for anything heavy. It keeps momentum going while starting to make the flow feel a bit more tailored.

Why it exists: second frictionless step, with a bit of personalization layered in.

### 3. Tutor Reveal
This is basically the "okay, this thing is real" moment. We stop asking questions for a second and show tutor variety.

Why it exists: adds product proof before asking for more effort.

### 4. English Level
Now we ask them where they are. By this point we've already shown different tutors and levels, so it doesn't feel like a test.

Why it exists: gets the user to start investing in their own profile.

### 5. Topics of Struggle
This is where it stops being abstract. We're not talking about "learning English" anymore, we're talking about interviews, meetings, travel, dating, real-life stuff.

Why it exists: ties the product to actual pain points.

### 6. Daily Practice Time
This makes the plan feel doable. It's not asking for some huge life change, just "how much time do you actually have?"

Why it exists: lowers the intimidation factor and gets a small commitment.

### 7. Personalization Reveal
This is the payoff step. We reflect their answers back so it feels like the plan is already being built.

Why it exists: gives the user a little hit of "this is for me."

### 8. Motivation
This one is more emotional than practical. It gets them to frame themselves as someone who is serious about improving.

Why it exists: turns interest into self-commitment.

### 9. Fluency Timeline
Now we add urgency. Once someone picks a timeline, the outcome feels more real.

Why it exists: pushes the user closer to wanting an actual plan.

### 10. Email Capture
The email ask comes last on purpose. By now they've answered a bunch of questions, seen the tutors, and been told the plan is ready.

Why it exists: this is the conversion moment, and it works better after the value setup.

## Why This Order Converts

The basic logic is:

- Start with easy, identity-based questions.
- Show that the product feels real.
- Get the user to define their own problem.
- Play that back as personalization.
- Add a bit of commitment and urgency.
- Ask for the email at the end, not the start.

If we ask for the email too early, it feels needy. If we ask after the user feels seen and the plan feels real, it feels earned.

## What We Measure

We already track the main stuff:

- when the funnel starts
- which steps are viewed
- which steps are completed
- when users go back
- when the email is submitted
- whether submission succeeds or fails
- where users drop before finishing

That's enough to see where people lose momentum, where they hesitate, and which parts of the flow are actually helping conversion.
